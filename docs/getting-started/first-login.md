# First login

When installation finishes, use the admin credentials reported by the installer. Keep the private installation summary accessible to authorized operators only.

## Logging in

1. Open the nova-ve address in your browser. Use HTTPS when TLS is configured.
2. Sign in with the admin username and password reported by the installer.
3. From the labs index, select **New Lab** to create your first lab.

If the page does not load, see [Troubleshooting](../operations/troubleshooting.md).
